# character-cc: licence and origin

- `avatar.js`, `clothing.js`, `materials.js`, `lifecycle.js`: fork of **CharacterCreatorXR** (MIT licence, Copyright (c)
  2026 Kasper Olesen) via the Contracts character plugin (`packages/character-plugin/src`). Headers and import paths changed.
- `sync_cc.mjs`: from the Contracts asset sync (`tools/sync_assets.mjs`, MIT, Copyright (c) 2026 Kasper Olesen).
- `index.js`: GameSystems, MIT (see `GameSystems/LICENSE`).

## Generated folders (never edit, never commit)

- `vendor/cc/`: CharacterCreator web modules, generated by `sync_cc.mjs`. They carry the licence of the synced
  CharacterCreator commit, recorded as `sourceCommit` in `vendor/cc/SYNCED.json`. CharacterCreator was **MIT up to
  commit `0d78054`** and is **GPL-3.0-or-later from 2026-10-03**. The copies in the games come from `dc664c07` (MIT).
  Syncing a later CharacterCreator commit brings GPL code into the game: do that only on purpose
  (`--commit`/`--source` an exported MIT tree otherwise).
- `assets/`: CharacterCreator `output/` GLBs, manifests and animation JSON (CC0 / per-asset licences in
  `assets/asset_licenses.json` and CharacterCreator's LICENSE-NOTES.md).
