# gore: licence and origin

- All files (`*.js`, `tools/*.mjs`): GameSystems, MIT (see `GameSystems/LICENSE`). Written for this extension.
- Insides (bones, ribs, organs, guts, brain), stump caps, blood, splat and wound textures: **procedural**, generated
  in code (`insides.js`, `materials.js`, `effects.js`). No third-party meshes, textures or sounds are used.
- `data/makehuman_cc.gibs.json` + `.gibs.bin`: generated by `tools/bake_gibs.mjs` from the synced CharacterCreator
  assets (`webxr-demo/public/avatar-assets`: the MakeHuman base body, garments and hair, CC0 / per-asset licences as
  recorded in `extensions/character-cc/LICENSE-NOTES.md`). The data holds triangle lists, interpolation recipes over the
  source vertices and a vertex-position fingerprint; it carries the licence of those source assets (CC0 for the
  MakeHuman base mesh and the bundled clothes/hair). Rebuild with the tool, never edit.
- No assets from Gunman Contracts or any other game are used.
