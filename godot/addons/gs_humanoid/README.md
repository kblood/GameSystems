# gs_humanoid

`gs_humanoid` is the shared humanoid data contract for Godot consumers. Its first
slice loads and validates the canonical joint list and the MPFB, VRM 1.0, VRM 0.x
and Mixamo rig maps. The source data lives in `extensions/humanoid/bone_maps.data.json`;
the Godot copy and comparison golden are generated by
`node godot/tools/gen_golden.mjs`.

This addon does not retarget poses or create skeletons. Those runtime features belong
to the later `gs_humanoid` port step and can build on the validated maps here.

```gdscript
var maps := GSHumanoidBoneMaps.load_data()
var vrm_map: Dictionary = maps["maps"]["vrm1"]
```

Run its source contract with:

```powershell
godot --headless --path godot --script res://addons/gs_humanoid/tests/gs_humanoid_bone_maps_tests.gd
```
