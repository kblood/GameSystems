# gs_grasp: licence and origin

The GDScript nearest selector ports the MIT GameSystems
`extensions/grasp/baked_grasps.js` public `nearestPose`/`quatAngle` operations and
`ANGLE_WEIGHT`/`HYSTERESIS` values. Copyright (c) 2026 Kasper Olesen; the repository
MIT licence applies. The source's canonical bake originated in the Godot hand-frame
grasp workflow; this addon contains no bake or avatar runtime code.

Tests and generator probes are original GameSystems work under the same licence.
The golden is generated by calling the public JS selector, with numerical queries
derived from `BAKED` and synthetic cases. It records source dependency hashes and
selected results rather than copying the bake. The existing `gs_grasp_data` addon
provides the canonical data copy; its `LICENSE-NOTES.md` retains the complete bake,
reference-hand and recording provenance. Importing those modules for the JS oracle
does not port their algorithms or prove avatar-asset/contact parity.
