# gs_grasp: licence and origin

The GDScript nearest selector ports the MIT GameSystems
`extensions/grasp/baked_grasps.js` public `nearestPose`/`quatAngle` operations and
`ANGLE_WEIGHT`/`HYSTERESIS` values. Copyright (c) 2026 Kasper Olesen; the repository
MIT licence applies. The source's canonical bake originated in the Godot hand-frame
grasp workflow; this addon contains no bake or avatar runtime code.

Tests and generator probes are original GameSystems work under the same licence.
The golden is generated by calling the public JS selector, with numerical queries
derived from `BAKED` and synthetic cases. It records source dependency hashes and
selected results rather than copying the bake. The existing `gs_grasp_data` addon
provides the canonical data copy; its `LICENSE-NOTES.md` retains the complete bake,
reference-hand and recording provenance. Importing those modules for the JS oracle
does not port their algorithms or prove avatar-asset/contact parity.

`GSGraspMerge` ports the public `mergePoses` function in MIT GameSystems
`extensions/grasp/record.js`, retaining its ordering, shallow-copy and reference
semantics. Its tests/probe are original GameSystems MIT work, Copyright (c) 2026
Kasper Olesen. The merge golden invokes that public function on synthetic records
and the existing canonical bake/accepted Grasp Studio recordings. It stores origin
and identity descriptors, not another canonical library. No recording, mirroring,
closure, CharacterCreator runtime or avatar calibration algorithm is copied here.

`GSGraspClamp` ports `clampRows` from the same MIT GameSystems
`extensions/grasp/grasp_validator.js` module. It reads the shared validator
ranges/comfort data through `gs_grasp_data`; no joint-limit table is duplicated in
this addon. Its golden invokes the public JS function for the canonical bake and
synthetic edge rows. The tests and probe are original GameSystems MIT work,
Copyright (c) 2026 Kasper Olesen.

`GSGraspThrowRelease` ports the public sampling and release math from MIT GameSystems
`extensions/grasp/throw_release.js`. It does not copy Nightfall's host-side glass
contact classifier or object-release integration. The golden invokes the public JS
functions; the GDScript, generator probe and tests are original GameSystems MIT work,
Copyright (c) 2026 Kasper Olesen.

`GSGraspValidator` ports the public `validateRows` diagnostic from MIT GameSystems
`extensions/grasp/grasp_validator.js` and reads ranges/comfort data from `gs_grasp_data`.
It does not clamp, score/select runtime quality or implement contact. The golden calls
the public validator over baked and synthetic rows; the GDScript, generator probe and
tests are original GameSystems MIT work, Copyright (c) 2026 Kasper Olesen.

`GSGraspHeldDrive` ports the public math/sampling helpers from MIT GameSystems
`extensions/grasp/held_drive.js` and reads tuning from `gs_grasp_data`. It does not
include host physics integration or the Nightfall runtime's drive implementation.
The golden calls the public JS helpers; the probe, tests and GDScript port are original
GameSystems MIT work, Copyright (c) 2026 Kasper Olesen.

`GSGraspShapeSdf` ports the MIT GameSystems `extensions/grasp/catalog.js`
`signedDistance` and `surfaceNormal` functions and uses shapes from the shared
`gs_grasp_data` catalog. The implementation, golden probe and tests are original
GameSystems MIT work, Copyright (c) 2026 Kasper Olesen; the golden invokes those
public JS functions and stores sampled outputs rather than duplicating the catalog.

`GSGraspVariants` ports selection behavior from MIT GameSystems
`extensions/grasp/baked_grasps.js` and uses `GSGraspMerge` for the public merge policy.
Its golden exercises the public JS `setGraspVariants` API and restores its module state;
the Godot utility itself is stateless. Probe/tests are original GameSystems MIT work,
Copyright (c) 2026 Kasper Olesen.

`GSGraspRecordedPoses` ports the public `isPose` and `recordedPoses` runtime filtering
from MIT GameSystems `extensions/grasp/record.js`. It intentionally skips invalid
individual entries and ignores optional metadata, unlike the stricter G3 source-file
reader. Its golden calls the public JS functions on synthetic documents; the
GDScript, probe and tests are original GameSystems MIT work, Copyright (c) 2026
Kasper Olesen.

`GSGraspMirror` ports the public `mirrorPose` reflection and copy behavior from MIT
GameSystems `extensions/grasp/record.js`. It does not validate or install the result.
The golden calls the public JS function on synthetic and canonical poses; the
GDScript, probe and tests are original GameSystems MIT work, Copyright (c) 2026
Kasper Olesen.

`GSGraspCapture` ports `handBasis`, `handLengthFromJoints`, `quatFromBasis`,
`rowsFromJoints`, `captureFromJoints` and `recordedPose` from MIT GameSystems
`extensions/grasp/record.js`. Its golden calls the public JS helpers;
the GDScript, probe and tests are original GameSystems MIT work, Copyright (c) 2026
Kasper Olesen.

`GSGraspClosure` ports the public `fingerChain` forward-kinematics helper from MIT
GameSystems `extensions/grasp/closure.js`. It does not search for contact, clamp
angles or integrate a runtime hand. The golden calls the public JS function; the
GDScript, probe and tests are original GameSystems MIT work, Copyright (c) 2026
Kasper Olesen.
